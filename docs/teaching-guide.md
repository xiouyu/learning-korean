# 教學指南（世宗韓國語 1A・40 音）

2026-10-16 照日文網站（[xiouyu/learning-japanese](https://github.com/xiouyu/learning-japanese)）的教學方式整理，讓之後在 Claude 或其他地方接手時，用同樣的方式教學和擴充網站。

## 學習者資料

- 台灣人，請一律用**繁體中文**、台灣的說法。
- **完全的韓文初學者**。已經用同樣的方式學過日文（五十音和《いろどり》入門 A1）。
- 希望照教材**一步一步學**，不要還沒教就先考試。
- 希望用互動網站學習，因為對話裡很多效果（隱藏答案、發音、描字）沒辦法呈現。

## 使用的教材

**《世宗韓國語》（세종한국어）改版 1A**，韓國世宗學堂財團出版，2022 年改版。初級是 1A、1B、2A、2B，入門從 1A 開始。

| 教材線上平台「누리 세종학당」（電子書、PDF、音檔，可能要註冊會員） | https://nuri.iksi.or.kr |
| 世宗學堂財團的教材清單 | https://www.ksif.or.kr/com/cmm/EgovContentView.do?menuNo=20102200 |

- 有韓文版和英文版，**沒有繁體中文版**，講解要自己用中文寫。
- 授權是**공공누리（公共授權）第 4 類**：要標示出處、不能商業使用、**不能改作**。所以：
  - 課本 PDF 和原始音檔只放在私人專案 `xiouyu/learning-korean-materials`，不要放進這個公開專案。
  - 網站上的講解用自己的話寫，照課本的課程順序和學習目標走，不要整段照抄課本。
  - 有用到課本內容的步驟要填 `source`，網站會顯示出處和授權。
  - 課本音檔能不能壓縮後公開放在網站上還不確定，在確認之前先用瀏覽器的韓文語音。
- 課程目錄：下載 1A 之後補在這裡。

## 教學方式

1. **先打好 40 音（韓文字母）基礎**，再進課本第 1 課。
2. **每一步只學幾個字母**，學會了才往下。
3. 每一步的講解格式：
   - 一句話說明這一步的規則（例如「在 ㅏ ㅓ ㅗ ㅜ 多加一短筆，就多一個 y 的音」）。
   - 欄位：**字｜羅馬拼音｜發音（對照注音）｜字母｜字形由來**。
   - 韓文字母沒有「來源漢字」，改成說明字形怎麼來的：母音是天（·）、地（ㅡ）、人（ㅣ）組成的；子音是照發音器官的形狀畫的（例如 ㄱ 是舌根擋住喉嚨的樣子）。
   - 重點：容易搞混的字（어／오、으／우、유 不是ㄩ）、記憶方法。
4. 練習方式：
   - **唸**：每個字大聲唸 5 遍。
   - **寫**：每個字寫 5 次，邊寫邊唸。筆順跟中文一樣，由上到下、由左到右。
   - **唸單字**：只用學過的字母組成的真實單字，先自己唸再看答案。漢字詞填 `h`（例如 이유＝理由），對台灣人很好記。
5. 學習者說「**下一步**」才進入下一步。
6. **不要還沒教就先考試**。測驗只放在學過之後，當作複習或解鎖。
7. 每學完一步，就把新內容加進網站的 `src/data/steps.json`。

## 學習路線

網站目前收錄第 1～2 步。之後照下面的計畫往下加（加之前可以再調整）：

| 步 | 內容 | 狀態 |
|---|---|---|
| 1 | 基本母音（一）아 어 오 우 으 이 | 已完成 |
| 2 | 基本母音（二）야 여 요 유 | 已完成 |
| 3 | 子音（一）ㄱ ㄴ ㄷ ㄹ（가 나 다 라） | 下一步 |
| 4 | 子音（二）ㅁ ㅂ ㅅ ㅈ | |
| 5 | 送氣音 ㅊ ㅋ ㅌ ㅍ 和 ㅎ | |
| 6 | 緊音 ㄲ ㄸ ㅃ ㅆ ㅉ（比較 가／카／까 三種音） | |
| 7 | 複合母音（一）ㅐ ㅔ ㅒ ㅖ | |
| 8 | 複合母音（二）ㅘ ㅙ ㅚ ㅝ ㅞ ㅟ ㅢ | |
| 9 | 收尾音（一）ㄴ ㅁ ㅇ ㄹ | |
| 10 | 收尾音（二）ㄱ ㄷ ㅂ 和它們的代表音 | |
| 11 | 連音和常見的發音變化 | |
| 之後 | 《世宗韓國語》1A 第 1 課起，一課分成幾步 | |

- 「學習路線」最後的「下一站」寫在 `src/data/index.ts` 的 `ROADMAP`，加完一步要改成再下一步。
- 頂端的進度格和「反切表」分頁會從字卡的字自動算出學過哪些字母（例如 가 會算到 ㄱ 和 ㅏ），不用另外設定。
- 有收尾音的步驟，字卡的 `o` 填收尾音、`ol` 填「收尾音」。
- 聽起來一樣的字（例如 애／에）要填相同的 `snd`，測驗時才不會放在同一題。
- 課本句子的步驟用 `"kind": "phrase"`，會話放在 `dialogs`，出處寫在 `source`（例如「《世宗韓國語》1A 第1課 p.20」）。
