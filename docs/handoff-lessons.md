## 每一課怎麼做

參考日文網站 `xiouyu/learning-japanese` 的 `src/data/steps.json` 第 34 步以後（《いろどり》第 1 課起）的做法。

### 分步

- 一課拆成 **5～6 步**，照課本的段落分：어휘 → 표현 → 문법 1 → 문법 2 → 듣고 말하기 → 읽고 쓰기。第 1 課就是這樣分的。
- 每一步 4～10 張卡片，內容太多就再拆。
- 每一步都要能出解鎖測驗（`npm test` 會檢查）。

### 資料格式

一步就是 `steps.json` 最後加的一筆，`id` 接著編號（第 1 課從 13 開始）。欄位定義在 `src/data/types.ts`，課本內容用 `"kind": "phrase"`：

```json
{
  "id": 13,
  "row": "自我介紹",
  "title": "저는 ○○이에요",
  "part": "第1課 課名",
  "kind": "phrase",
  "rule": "一句話說明這一步要學會做什麼。",
  "letters": [
    {
      "k": "안녕하세요?",
      "r": "annyeonghaseyo?",
      "z": "你好。見面打招呼，對誰都可以用。"
    }
  ],
  "dialogs": [
    {
      "label": "① 初次見面（課本 p.28 聽力）",
      "lines": [
        { "who": "A", "t": "안녕하세요? 저는 ○○이에요.", "m": "你好，我是○○。" }
      ]
    }
  ],
  "notes": ["重點說明…"],
  "words": [{ "w": "학생", "r": "haksaeng", "m": "學生", "h": "學生" }],
  "source": "《세종학당 한국어》1 第1課 p.20-21",
  "note": "學習路線上的小註解"
}
```

| 欄位 | 寫法 |
|---|---|
| `letters[].k` | 課本的句子或詞語（韓文原文，照課本） |
| `letters[].r` | 羅馬拼音，用韓國官方的國語羅馬字表記法，照**實際唸法**（連音、鼻音化後的音），例如 감사합니다 → gamsahamnida |
| `letters[].z` | 中文意思＋什麼時候用；有發音變化就寫「唸成 [감사함니다]」 |
| `letters[].ex` | 容易出錯的句子標 `true`（顯示「注意」） |
| `words[].h` | 漢字詞才填漢字，例如 학생 填「學生」；固有詞、外來語不填 |
| `dialogs` | 課本會話。`who` 用人名或 A／B，`m` 寫中文翻譯 |
| `source` | 課本的課和頁碼。有用到課本內容就一定要填 |

`notes` 寫文法和用法的重點，**用自己的話寫**，不要照抄課本的說明；可以比較中文、台語的說法幫助理解。

### 寫法要求

- 繁體中文、台灣用語（例如「影片」不是「視頻」、「手機」不是「手提電話」）。
- 每一步只放這一步要學的東西，**不要還沒教就先考**：單字和例句只用學過的文法。
- 文法說明要具體：接在什麼後面、有沒有收尾音怎麼變（例如 이에요／예요：有收尾音接 이에요，沒有接 예요）。
- 課本有的練習題不用全部做進去，挑代表性的句子放進 `letters` 或 `words` 就好。

### 音檔

**這套教材不能轉載音檔**（版權頁沒有공공누리標示，明文禁止引用、摘錄），所以：

- `audio` 欄位一律不填，網站會自動用瀏覽器的韓文語音唸字卡和會話。
- 不要把課本或練習本的 mp3 複製進 `public/`。
- 音檔只在自己對照發音時聽，不要進版控。

### 其他要改的地方

- `src/data/index.ts` 的 `ROADMAP` 下一站：改成下一課的課名。
- `src/pages/LearnPage.vue` 最下面的出處那一行（`step.source` 後面）：改成實際的書名和授權。
- `docs/teaching-guide.md` 的「學習路線」表格：每做完一課就加一列（第幾課｜第幾步到第幾步｜每步內容）。
- `README.md`、`CLAUDE.md` 開頭的現況描述（目前寫到第 31 步）。

## 每做完一課

1. `npm run typecheck`、`npm test`，都要通過。
2. `npm run dev` 打開網站，實際點過這一課的每一步：字卡、播放發音、會話、解鎖測驗、手機寬度的畫面。
3. commit（訊息用繁體中文，例如「加入《세종학당 한국어》1 第 1 課（第 13～18 步）」），push 到 `main`。
4. 到 GitHub 的 Actions 確認部署成功。

## 不要做的事

- 不要把課本 PDF 或整頁圖片放進這個專案（這是公開專案）。課本原始檔只留在使用者的備份或私人專案。
- 不要改 `src/lib/progress.ts` 的資料格式（學習者已經有進度紀錄）。
- 不要改已經上線的第 1～12 步的 `id`。
- 不要把講解寫成課本原文的翻譯，要用自己的話說明。
